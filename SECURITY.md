# Security Policy

## Authorized use

Keld is intended for systems you own or are explicitly authorized to test. Do not use it against targets outside an agreed scope. Unauthorized scanning or access may be illegal.

## Supported versions

Security fixes are applied to the latest released version on the default branch.

## Reporting a vulnerability

Please report security issues privately via GitHub Security Advisories on [Leo-Galli/keld](https://github.com/Leo-Galli/keld), or email the maintainer through the contact listed on the GitHub profile. Do not open a public issue for undisclosed vulnerabilities.

Include steps to reproduce, affected version, and impact. You should receive an acknowledgement within a reasonable time.

## Product constraints

Keld does not include malware, persistence mechanisms, credential theft, exploitation payloads, or AV/EDR evasion. Reports that request those features will be declined.
